This report accompanies the paper “WOODELF-HD: Efficient Background SHAP for High-Depth Decision Trees” (arXiv link: ___). It is the m = 100 report with one more algorithm, WoodelfHD on a GPU. The background dataset has m = 100 rows instead of the full training set.

For each dataset we trained LightGBM models with maximum depths 6, 9, 12, 15, 18, and 21 (and 25 for California Housing). We then used each algorithm to compute Background (Interventional) Shapley values and Shapley interaction values. This report compares the running time of the different algorithms on these tasks. WoodelfHD GPU runs on the same models, explained rows and background rows as the CPU algorithms, and on the same number of trees as WoodelfHD on CPU.

Experiment Summary

SHAP Algorithms evaluated include the widely used shap package, PLTreeSHAP, the original Woodelf algorithm, and WoodelfHD on CPU and on GPU.

Running Environment: The CPU algorithms were run on Google Colab using the CPU runtime with high memory enabled (50 GB memory). WoodelfHD GPU was run on Google Colab using the T4 GPU runtime with high memory enabled. For WoodelfHD GPU, one untimed warmup call per task pays the one-time GPU start-up costs, and each timing ends only after the GPU has finished its work.

Parameters

Parameter Values Details
Max Depth D = 6, 9, 12, 15, 18, 21 We trained models with increasing tree depth. The graphs show how runtime changes as depth grows.
Number of trees T = 100 LightGBM models were trained with 100 trees. In some cases where running all trees was too expensive, results were computed on 10 trees or a single tree and then extrapolated.
Explained samples n = test set size The models are trained on the whole dataset, and the explained rows are drawn at random from it. Their number equals the size of the dataset's test set. For SHAP interaction values we used n = 10,000 samples (California Housing: 4,128).
Background data size m = 100 The background dataset is 100 rows drawn at random from the dataset, disjoint from the explained rows. All algorithms, including the shap package, used all 100 rows.
